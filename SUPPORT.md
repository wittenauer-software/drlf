# Support

DRLF v0.1 is a repository-first project supported on the documented Windows 11 x64 environment.
Support is community and maintainer best-effort; there is no service-level agreement, hosted
service, Linux support commitment, or guarantee that a public data source remains available.

Use a public issue only for reproducible software defects, documentation problems, or generalized
feature requests that contain no real identity, claim, research lead, allegation, PHI, beneficiary
data, credential, private URL, or retained source output. Blank issues are disabled. Use the supplied
templates and a synthetic reproduction.

Do not ask the project to assess a named provider or accept a fraud tip. For security vulnerabilities,
follow `SECURITY.md`; do not post details publicly. For conduct, follow `CODE_OF_CONDUCT.md`.
