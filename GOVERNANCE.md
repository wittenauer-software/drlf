# Governance

Wittenauer Software is the initial DRLF maintainer. Maintainers set release scope, review changes,
protect the public/private research boundary, and may appoint additional maintainers through a
documented pull request.

Changes use reviewable pull requests. External contributions require explicit verified-maintainer
approval before merge. Skill changes require the separate proposal and permission gate described in
`AGENTS.md`. Security handling, conduct moderation, releases, packages, hosted services, and public
communications require their own authorization; ordinary code approval does not imply them.

Decisions should record alternatives, evidence, safety and compatibility impact, dissent, and the
reason for the outcome. Maintainers must recuse from final handling when they are a subject of a
conduct report or have a material conflict. For GitHub-policy violations, the reporter may use the
scoped GitHub abuse-reporting process described in `CODE_OF_CONDUCT.md` as independent escalation.

DRLF has no authority to investigate or adjudicate healthcare fraud. Maintainers will remove or
contain identifiable allegations from project surfaces under the incident policy and will not turn
them into project research.

## Public-content incident procedure

If identifiable healthcare material, private workspace content, credentials, or an allegation appears
on a project surface, stop substantive public discussion and do not repeat the details. Record only
the minimum locator needed for an authorized maintainer to find the material, in a verified private
location. Closed sensitive intake does not authorize sending the material through another channel.

A verified maintainer should review the affected surface and use authorized moderation controls to
hide, remove or restrict the exposed content. If a credential is involved, its authorized owner must
revoke or rotate it. Check other reachable copies and retain a private action log; deletion or a revert
does not prove that every copy is gone. GitHub-policy violations may use the scoped platform process
in `CODE_OF_CONDUCT.md`. Any request for platform assistance must disclose only the necessary locator
and require authorization before transmission.

Resume public activity only after the maintainer records the containment assessment and remaining
exposure privately. Do not convert incident material into a case, publish a finding, or promise complete
erasure. Publication and other external actions retain their separate authorization requirements.
